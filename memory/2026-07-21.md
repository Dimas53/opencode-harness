## Reorg pattern for notes/

When moving a tracked file out of git:
```
git checkout -- <file>        # restore if deleted
mv <file> <new_location>      # move to archive dir
git rm --cached <file>        # stop tracking, keep local
```
New location stays untracked (not staged).
