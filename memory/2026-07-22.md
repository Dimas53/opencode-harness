### DoD pre-commit hook blocks commit on root-level doc changes
When editing INSTALL.md, README.md, Makefile (not in docs/ or instructions/ directories),
the docs matrix check (step 5) fails because it only watches docs/ and instructions/.
FIXED (2026-07-30): dod.sh Step 5 now recognizes INSTALL.md and README.md as
valid docs updates directly (DOCS_FILES check). `--no-verify` was never the
right fix — it disables all 7 DoD checks, not just this one. Do not use it;
if a future false-positive appears, report it and fix the specific check.
