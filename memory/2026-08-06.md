# 2026-08-06 (second session)

## Workarounds
- `git stash push -- <paths>` followed by `git stash pop` can produce a
  merge conflict even when the popped paths don't overlap the files
  changed in between, if those unrelated files were already staged with
  different content at stash time. Resolve by keeping the post-stash
  (currently committed) version and re-applying — don't assume the
  stash's content should win.
- `grep -c PATTERN file` prints "0" **and** exits 1 when there are zero
  matches. `SESSION_COUNT=$(grep -c ... || echo 0)` doubles the output
  ("0\n0") instead of falling back cleanly — use
  `SESSION_COUNT=$(grep -c ...) || SESSION_COUNT=0` instead.
- Any `diff a b | head` (or piped to anything) inside a script with
  `set -e -o pipefail` aborts the script the moment `diff` finds a
  difference (`diff` exits 1 for "files differ", not just for a real
  error). Add `|| true` after the pipeline wherever you actually want to
  keep going and just show the diff.
- `find ... -not -path ...` fails under this session's `rtk find`
  wrapper ("does not support compound predicates"). Use plain `ls | grep`
  instead of `find -not`/`-exec` when `rtk` is intercepting `find`.
- macOS's default shell here has no `timeout` command — use the Bash
  tool's own `timeout` parameter instead of shelling out to `timeout`.
